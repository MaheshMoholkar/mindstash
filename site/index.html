For Claude Code and Codex

See what your agents remember. Clean up what they shouldn't.

Claude Code and Codex save memories and load skills on their own, and CLAUDE.md files keep growing. Over time some go stale, some land in the wrong folder, some repeat or contradict each other. MindStash finds them, tells you why each one was flagged, and helps you clean up.

$ npx mindstash
Read the docs

Node 20+ · MIT · nothing changes without asking

01 / how it works

Scan. Flag. Fix.

scan

Everything your agents load, in one place

Memories, skills, CLAUDE.md and AGENTS.md, for Claude Code and Codex, globally and per project. The terminal UI opens with your last scan while it refreshes in the background.

flag

Every finding says why

Start with Stale and glance at the preview to see what changed. Open a finding for the evidence, or switch to Token cost to see what loads each session.

fix

Delete, archive or move

Move a misplaced memory to the project where it belongs, or delete and archive stale notes. Review the plan first, then press u to undo a change.

Terminal snapshots from a fictional workspace. Select a tab to switch screens. The shortcuts shown run in MindStash.

03 / safety

Built to be trusted with your files

Asks first

Nothing changes until you confirm. Fixes only take finding ids from the latest scan, and refuse files that changed since.

Backed up in git

Every fix is saved to ~/.mindstash/backups before it runs. mindstash undo reverts it, and mindstash restore brings back anything archived.

Never rewrites a word

Look-alike memories are shown side by side. MindStash suggests a merge; you make it in your own editor.

Leaves your agents alone

Claude Code and Codex keep saving memory their own way. No new store, nothing to sync.

04 / from your agent

Or just ask your agent

One command adds /mindstash to Claude Code and $mindstash to Codex. Your agent runs the scan, checks each finding against the repo and waits for your OK. No API key: the agent you already use judges contradictions.

Optional: install-statusline shows what's new in Claude Code's status line, and install-hook adds a one-line note when a session starts. Both read the cached scan, so sessions don't slow down.

$ npx mindstash install-skill
