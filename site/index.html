For Claude Code and Codex

See what your agents remember. Clean up what they shouldn't.

Claude Code and Codex save memories and load skills on their own, and CLAUDE.md files keep growing. Over time some go stale, some land in the wrong folder, some repeat or contradict each other. MindStash finds them, tells you why each one was flagged, and helps you clean up.

$ npx mindstash

Node 20+ · MIT · nothing changes without asking

01 / how it works

Scan. Flag. Fix.

scan

Everything your agents load, in one place

Memories, skills, CLAUDE.md and AGENTS.md, for Claude Code and Codex, globally and per project. Scanning never changes your agents' files.

flag

Every finding says why

Each one comes with its reason, a confidence level and what it costs in tokens every session. Dismiss a false alarm once and it stays quiet.

fix

Delete, archive or move

You pick what goes and see the plan first. A backup is saved to git before anything changes, and u undoes it.

02 / what it flags

Checks for memories, CLAUDE.md and skills

Each check has a confidence level, so you know which findings to act on first.

RuleConfidenceMeaning
Memories
missing-projecthighMemories for a project folder that's gone.
missing-pathhighMentions a file or folder that no longer exists, checked against the repo's git files.
past-eventmediumA date that was coming up when the memory was saved, and has now passed.
version-mismatchmediumSays "Node 16" while the repo declares 22 in package.json, .nvmrc, go.mod and the like.
missing-skillhighSays to run a /command that isn't installed.
wrong-scopemediumA note about one project saved in a parent folder like ~, so it loads everywhere. Can be moved.
similarmedium–highNear-duplicate memories. Suggested, never merged.
relearnedmediumLooks like a memory you deleted with MindStash. The agent saved it again.
contradictionmediumTwo notes that load together disagree, as judged by your own agent.
CLAUDE.md, AGENTS.md and MEMORY.md
instructions-too-bigmedium–highA CLAUDE.md or AGENTS.md over ~4,000 tokens, loaded in full every session. Points at its biggest and log-like sections.
broad-instructionsmediumA CLAUDE.md in a parent folder like ~ that loads in every project below it.
agents-too-longhighAGENTS.md files for a folder over the 32 KiB Codex reads.
too-long · unindexedhigh–mediumMEMORY.md over 200 lines, links to missing files, or memory files it doesn't list. MindStash can link those back in.
Skills
skill-duplicate · skill-overlapmedium–highA skill installed twice, or two skills that would trigger on the same request.
codex-skill-budgetlowCodex skill descriptions past the listing budget Codex documents.
03 / safety

Built to be trusted with your files

Asks first

Nothing changes until you confirm. Fixes only take finding ids from the latest scan, and refuse files that changed since.

Backed up in git

Every fix is saved to ~/.mindstash/backups before it runs. mindstash undo reverts it, and mindstash restore brings back anything archived.

Never rewrites a word

Look-alike memories are shown side by side. MindStash suggests a merge; you make it in your own editor.

Leaves your agents alone

Claude Code and Codex keep saving memory their own way. No new store, nothing to sync.

04 / from your agent

Or just ask your agent

One command adds /mindstash to Claude Code and $mindstash to Codex. Your agent runs the scan, checks each finding against the repo and waits for your OK. No API key: the agent you already use judges contradictions.

Optional: install-statusline shows what's new in Claude Code's status line, and install-hook adds a one-line note when a session starts. Both read the cached scan, so sessions don't slow down.

$ npx mindstash install-skill 
> /mindstash

● Scanned 39 memories and 12 skills (~7,400 tokens per session).
  5 things look off:

  1. hackathon-notes (~): mentions Oct 15–18, ended 17 days ago
  2. old-api-endpoints (~/work/api-server): src/api/v1/ is gone
  3. node-version ↔ ci-setup: one says Node 16, the other Node 22
  4. prefers-short-answers ↔ concise-responses: look like duplicates
  5. MEMORY.md is 240 lines; only the first 200 load

  Want me to delete 1 and 2? For 4, I can open both files.

> delete 1 and 2, ignore 3

● Done. Deleted 2 memories, marked 1 as not a problem.
  Saves ~620 tokens per session. Say "undo" to revert.
